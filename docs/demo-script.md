# Competition demo script

## Setup

Use the Expo preview with the default fictional demo. No real opportunity, account, or uploaded document is required.

## 90-second path

1. **Home:** point to “Your next action” and the readiness metrics. Explain that ActionLayer prioritizes a concrete next step instead of opening with a chat.
2. **Agents:** open the Northstar Build Challenge. Show that a Competition Agent contains a plan, deadline, task states, and an at-risk signal.
3. **Review:** open claims. Show a confirmed organizer, an inferred deadline with confidence, and a missing deliverable. Confirm the deadline to demonstrate the human review gate.
4. **Dependencies:** return to the agent. Start “Choose a problem and concept.” Show that “Create the project repository” is blocked until the prerequisite is complete.
5. **Evidence:** attach a short evidence explanation to a task. Show the separate partial verification record and its limitation.
6. **Audit:** run the readiness audit. Open Activity to show the audit, claim review, source capture, and evidence events.
7. **Offline:** toggle offline mode. Explain that the current demo state is local and persists through AsyncStorage, while the API schema supports server-authoritative synchronization.

## Claims to make

- “ActionLayer turns source material into an inspectable requirement graph.”
- “The agent can suggest, but it does not silently assert that an inferred claim is true.”
- “Evidence is attached to a requirement and carries its own verification limitations.”
- “The demo content is fictional and labeled as such.”

## Claims not to make

- Do not say the Northstar challenge is real.
- Do not say a user declaration is externally verified.
- Do not describe the current mock extraction adapter as a production AI provider.
- Do not imply that demo mode is a complete production identity boundary.
